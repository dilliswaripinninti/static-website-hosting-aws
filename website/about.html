How a request travels

A visitor requests the CloudFront domain. CloudFront answers from its cache, or signs a request to S3 using Origin Access Control and then caches the response.

Amazon S3

Stores index.html, about.html, 404.html, CSS and JavaScript. Public access is blocked.

CloudFront

Terminates HTTPS, caches content at edge locations and serves index.html as the default root object.

Origin Access Control

Lets CloudFront sign its requests to S3. The bucket policy trusts only this one distribution.

IAM and the CLI

A scoped IAM user uploads files and creates cache invalidations from PowerShell.
