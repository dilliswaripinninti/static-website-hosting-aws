Served from the edge, stored in a private bucket.

EdgeFolio is a static website hosted on AWS. Visitors never touch the S3 bucket: CloudFront fetches files over HTTPS using Origin Access Control and caches them close to every reader.

What this setup gives you

Each part of the stack has one job.

Global delivery

CloudFront caches pages at edge locations, so readers load files from a nearby location instead of your bucket's Region.

Locked-down storage

A bucket policy allows reads only from your CloudFront distribution. Direct S3 URLs return 403.

Least-privilege deploys

The deploy user can write to one bucket and invalidate one distribution, and nothing else.

Friendly errors

Missing pages return your own 404 page with a real 404 status code.
